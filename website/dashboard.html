Installation Help

WordPress: Add to Appearance → Theme Editor → footer.php, right before </body>.

Shopify: Online Store → Themes → Actions → Edit code → theme.liquid, paste before </body>.

Squarespace: Settings → Advanced → Code Injection → Footer.

Wix: Settings → Custom Code → Add Custom Code, choose "Body — end", paste the snippet.

Reload your site and Orby should appear within 5 seconds. If she doesn't show up, contact support@twickell.com with a screenshot.
