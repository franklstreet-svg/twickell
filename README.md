My Orby — twickell.com

This is the public marketing + sales-funnel site only. It deliberately
runs WITHOUT HuggingFace persistent storage so no paying customer's
business data ever touches the cloud. Per Frank's product promise,
the actual Orby install lives on each customer's OWN computer
(Windows or Mac), and their chats/leads/business profile/learned
answers stay on their machine — never here.

Sales-funnel data (visitor demo chats, legal acceptance records,
B2B intent tokens) is short-lived and wipes on container restart.
That's intentional — these aren't customer business records.
